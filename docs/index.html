What 132 Submissions Say About GDPR and Scientific Research

This explorer organises 132 written submissions to the EDPB's public consultation on Draft Guidelines 1/2026 (the GDPR and scientific research) into a browsable hierarchy of themes, subthemes, and specific issues, built by having an LLM read every paragraph, name the individual arguments it raises, and cluster those arguments rather than the raw text. To use it: click a theme in the left-hand tree to expand its subthemes and issues; selecting any node shows how many submissions raised it, the balance of support/opposition/concern, and representative quotes linked back to the original source PDF. See the methods page for how this was built and its limitations, or the dashboard for a one-page stance overview across all themes.
